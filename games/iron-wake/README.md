# Heavy Rig (formerly Iron Wake)

The game is maintained in [DeeGeeGames/heavy-rig](https://github.com/DeeGeeGames/heavy-rig)
and published at [heavyrig.deegeegames.com](https://heavyrig.deegeegames.com/).

The old `/games/iron-wake/` route redirects with query parameters and fragments
preserved. The launcher thumbnail remains here. Source, assets, and the existing
regression suite moved to the standalone repository.

The owner chose a fresh start on the new domain. Browser saves and preferences
are origin-scoped: existing `iron-wake:campaign:v1` and `iron-wake:profile:v1`
data are not deleted, but do not transfer. Heavy Rig uses its own namespaced keys.
