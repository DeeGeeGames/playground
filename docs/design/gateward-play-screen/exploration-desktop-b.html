Control coverage and interaction assumptions
Fitting and departure remain overlays on this screen. Mount details contain build, upgrade and sell; escorts contain purchases and mode-specific rally or sector orders. Sensors own integrity, repair and contact details; selecting a hostile exposes priority / clear priority. Reactor details contain all four presets and explicit donor → recipient transfers. Interdiction uses preview → aim → confirm / cancel. Aegis and hull repair remain direct actions. Menu contains pause, sound, fullscreen, reset camera, help, mode and restart. Systems Trial adds elapsed time and deadline alongside route progress.

Opening a command panel keeps combat running; opening Menu pauses and holds orders, matching current behavior. UI pointer events must not reach the camera or battlefield. Escape first cancels placement or closes a panel. Controls must retain keyboard focus and status cannot rely on color alone. Buttons here demonstrate navigation only; this is not a playable simulation or a hardware-tested layout.
